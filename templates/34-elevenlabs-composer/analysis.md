# 参考片拆解：ElevenLabs · Introducing Composer, a section-by-section song editor.

- 规格：原片 1080p，30 fps，59.12 秒，整体响度 −9.0 LUFS，约 112 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部黑底流体质感的功能片。标志缩小成产品名，首页输入框和缩略图，大号输入胶囊里逐字打出歌词，青色流体上弹出段落胶囊，折叠成歌词面板，再缩成速度卡和调式滚轮，接着是声波时间线和漂浮的声波卡片，最后产品名和标志框。

## 视觉规则

- **配色**：纯黑底，流体青色是唯一的强调色，界面卡片深灰。
- **字体**：无衬线大字，产品名后有一个彩色句点。
- **镜头**：大多正面构图，卡片缩放和折叠代替推拉。
- **节奏**：6 个剪辑点，约 112 BPM。

## 换成 MosMos

写歌 → 听写；歌词 → 原话；段落胶囊（主歌、副歌…）→ 场景（飞书 / 微信、邮件、文档…）；歌词面板 → 邮件正文；速度卡 → 润色三档；调式滚轮 → 场景滚轮；声波时间线 → 原话里的口头禅被去掉。

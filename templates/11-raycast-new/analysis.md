# 参考片拆解：New Raycast. Coming 2026

- 出处：Raycast 官方 YouTube，2025，<https://www.youtube.com/watch?v=Mi173xGb0ZA>
- 规格：1920×1080，30 fps，38.59 秒，整体响度 −13.2 LUFS
- 方法同模板 03。

## 一句话

黑色缎面一样的 3D 曲面在背景里缓缓流动，前面是磨砂玻璃质感的界面，镜头贴得很近、斜着拍、只有一条对焦带清楚。搜索框、打字、结果列表、快捷键面板、剪贴板历史、一格格表情在选择框下滑过、一颗小小的语音胶囊、AI 问答、带红绿灯的窗口、进度清单、更新提示。最后是纯黑底上一行行很小的等宽字，结尾一个极小的 logo。

## 视觉规则

- **配色**：几乎只有黑、灰、白。唯一的颜色是选中框（橙、青）和偶尔一点绿色。
- **质感**：背景是有高光的黑色缎面；界面是半透明的玻璃，带细描边。
- **镜头**：微距、倾斜、浅景深（画面上下都是虚的），缓慢推移。
- **字体**：界面里是系统无衬线；结尾的说明字是等宽小字，全大写，字距大。
- **节奏**：前 28 秒是界面，13 个剪辑点；后 10 秒只有黑底小字，几乎静止。

## 节拍

- librosa 和 tempogram 都给出 **129 BPM**（一拍 0.465 秒），首拍约 1.0 秒。
- 音乐是暗色极简电子：低频脉冲、短促的 hi-hat、滤波和弦；黑底小字段只剩很稀的滴答。

## 动效词汇

缎面流动；玻璃界面斜拍；浅景深对焦带；打字出结果；选择框跳格；卡片横向滑动；小胶囊波形；清单打勾；黑底等宽字替换。

## 换成 MosMos 的对应

| 参考 | MosMos 版 |
|---|---|
| 搜索框 Search | 按 Fn 说话，或输入 |
| 打字 clipboard + 结果 | 打字「热词」，结果是热词词库里的条目 |
| 操作菜单、快捷键面板 | 润色风格菜单；Fn + ⇧ 快捷键面板 |
| 剪贴板历史 | 今天的输入历史 |
| 表情网格和滑动卡片 | 场景卡片网格（飞书、邮件、文档、提示词、终端…）在选择框下滑过 |
| 小语音胶囊 | MosMos 的语音胶囊 |
| AI 问答 Ask anything | 场景列表 + 打字提问「整理今天的会议，列出待办」 |
| 红绿灯窗口 | 会议记录窗口 |
| 进度清单 | 三项依次完成：正在整理多人逐字稿 / 会议总结 / 待办事项 |
| Checking for updates… | 正在写好… |
| 黑底等宽小字 | 新 场景识别 / 新 热词词库 / 新 会议记录 / 新 MOSMOS / 新 MOSMOS + MOSMOS.IO |
| 极小 logo | 极小的 MosMos logo |

小尺寸界面在倾斜之后会跑出画面，模板里用 `tc()` 按倾斜后的位置重新居中；缎面加大了模糊，避免看起来像条纹。

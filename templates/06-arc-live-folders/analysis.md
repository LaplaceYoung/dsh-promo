# 参考片拆解：Introducing Live Folders in Arc | Your sidebar is alive

- 出处：The Browser Company 官方 YouTube，2024-04-11，<https://www.youtube.com/watch?v=x1TV6rBi_jM>
- 规格：1440×1080（4:3），23.976 fps，29.95 秒，整体响度 −11.9 LUFS（很响）
- 方法同模板 03：原生帧逐帧差分找剪辑点，4 fps 抽帧通读，关键帧抄字、取色，onset 自相关 + 网格拟合求速度。参考片素材只留在本地。

## 一句话

满屏品牌蓝上的白色粗体大写字卡，和斜拍的屏幕微距、真人镜头快速交替，几乎每拍一刀。字卡连起来是一句话：YOUR SIDEBAR / IS ALIVE / GITHUB / PULL REQUESTS / IN ARC AUTOMATICALLY / LIVE FOLDERS / LAND TODAY。最后是蓝底白色 logo。

## 视觉规则

- **配色**：字卡 91–96% 的像素是品牌蓝 #3030F8，字是纯白。屏幕镜头里 Arc 侧栏是粉色，背景是暖色桌面。
- **字体**：很粗的无衬线大写，行距很紧，居中。最后一张 LAND TODAY 明显更小。
- **字卡内换词**：YOUR → YOUR SIDEBAR（约 6.2 s）、IN ARC → AUTOMATICALLY（约 18.2 s），不切镜头，只换字。
- **屏幕镜头**：显示器斜拍，焦点只落在按钮或侧栏的一小块，其余虚掉；手持感很轻。
- **节奏**：23 个剪辑点，平均 1.3 秒一刀，最短 0.63 秒。

## 节拍

- 网格拟合得到 **约 125 BPM**（一拍 0.48 s），网格相位从 22.856 s 的剪辑点推算为 0.296 s。字卡的入点大多落在拍上。
- 音乐是明亮的电子流行：四拍底鼓、拍手、八分音符的和弦短音。
- 19.0–22.9 s 真人讲话时，音乐明显变薄（RMS 降到 0.03–0.04），其余段落每 2 小节有一次重音。

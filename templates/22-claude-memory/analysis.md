# 参考片拆解：Anthropic · Claude now has memory

- 出处：Anthropic 官方 YouTube，2025，<https://www.youtube.com/watch?v=PupmfSttxlc>
- 规格：原片 1080p，29.97 fps，59.0 秒，整体响度 −24.2 LUFS，约 87.5 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部温和的功能片，主题是让助手记住信息。米色纸面上，一条手绘线变成思考云，再变成设置卡片，打开两个开关；卡片里列出正在整理的记忆；接着在聊天里提一个请求，助手调用记忆；一个橙色圆点放大成八角框，里面整理一张张卡片；回到回复，回复的纸折起来变成信封，最后标志。

## 视觉规则

- **配色**：米色 #F0EEE6 左右的纸面、灰绿色的聊天底，品牌橙只用于中段的八角框；卡片是近白色。
- **插画**：黑色手绘线条，笔画慢慢长出来。
- **字体**：衬线标题 + 无衬线正文，回复逐字写出。
- **节奏**：11 个剪辑点，87.5 BPM，换场多用形状变形（线 → 云 → 卡片、圆点 → 八角框、纸 → 信封）。

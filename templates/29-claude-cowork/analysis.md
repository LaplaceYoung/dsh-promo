# 参考片拆解：Anthropic · Introducing Cowork: Claude Code for the rest of your work

- 出处：Anthropic 官方 YouTube，2026，<https://www.youtube.com/watch?v=UAmKyyZ-b9E>
- 规格：原片 1080p，24 fps，68.64 秒，整体响度 −32.3 LUFS，约 110 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部安静的产品发布片。米色底一句话开场，网格底上的切换开关变成标志；然后是任务首页、选文件夹、输入需求、问答卡、对话气泡、进度卡、日历、生成内容列表和一份演示文稿；最后输入框特写和标志。

## 视觉规则

- **配色**：米色和浅色网格底，白色卡片，橙色只用在发送按钮和小标志上。
- **字体**：衬线标题和结尾字，无衬线界面字。
- **镜头**：卡片和输入框常被推近到 2–3 倍，再拉远看整窗。
- **节奏**：13 个剪辑点，约 110 BPM，结尾约 6 秒是标志。

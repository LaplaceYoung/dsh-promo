# 参考片拆解：Anthropic · Claude can create and edit files

- 出处：Anthropic 官方 YouTube，2025，<https://www.youtube.com/watch?v=EV89Ws8Ui9Y>
- 规格：原片 1080p，24 fps，59.56 秒，整体响度 −17.8 LUFS，约 94 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部温和的功能片。米色底上手画的线稿开场，然后是暖白界面的大字特写：用户请助手把一份数据做成报告，灰色遮罩下显示分析过程和代码，生成的文档和表格逐页翻过，再在表格里改一个数字，最后线稿图标收尾。

## 视觉规则

- **配色**：米色底，暖白界面，灰色半透明遮罩表示「正在处理」；橙色只用在发送按钮和小标志上。
- **字体**：衬线大标题，无衬线正文，处理过程用等宽字体。
- **镜头**：界面特写为主，推近到输入框和高亮的词，再拉远看整窗；文档和表格是在窗口里滚动。
- **节奏**：19 个剪辑点，约 94 BPM，中间有几个 0.5–0.7 秒的快切。

## 换成 MosMos

数据分析请求 → 会议实时听写；附件 → 热词卡片；灰色遮罩下的代码 → 会议结束后整理总结和待办；生成的报告文档 → 会议纪要（结论、待办表格）；表格 → 进度表格里用语音填一个单元格；对话追问 → 在文档里用语音加一段润色好的话。

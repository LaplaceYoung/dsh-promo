# 参考片拆解：Figma · Code Layers: Collaborate with code on the canvas · Figma

- 出处：Figma 官方 YouTube，2026，<https://www.youtube.com/watch?v=UMDUAHmhkT8>
- 规格：原片 1080p，24 fps，34.88 秒，整体响度 −13.3 LUFS，约 128 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部节奏很快的设计工具功能片。白底一句话开场，左边一个词不断替换、右边换成对应的界面；一面等宽代码字墙拉远变成画布上的一块；灰色画布上一排排手机画板，几个带名字的彩色光标在上面协作；黑底两句结论，最后彩色像素块拼成代码片段，再收成标志。

## 视觉规则

- **配色**：白底开场，灰色 #E5E5E5 左右的画布，画板是浅色，光标是饱和的蓝、橙、粉、绿；结尾黑底。
- **字体**：开场和结论是中等字重的无衬线；字墙是等宽字体。
- **镜头**：画布镜头是连续的推拉和平移，画板很密。
- **节奏**：11 个剪辑点，开场换词每 1.2 秒左右一次，跟 128 BPM 的拍子走。

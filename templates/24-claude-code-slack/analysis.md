# 参考片拆解：Anthropic · Claude Code in Slack

- 出处：Anthropic 官方 YouTube，2025，<https://www.youtube.com/watch?v=XpXImenrSPI>
- 规格：原片 1080p，30 fps，41.1 秒，整体响度 −10.8 LUFS，约 93 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部明快的集成功能片。米色底上手画的大括号和对话泡开场，对话泡放大成团队聊天窗口；在频道话题里叫来助手，助手的状态卡片放大显示进度；点开会话页看任务步骤和代码块；完成后回到话题，最后一颗绿色按钮弹出，再是标志。

## 视觉规则

- **配色**：米色 #E3D9C6 左右的底，白色界面，深色侧栏；只有结尾的按钮是绿色。
- **插画**：黑色手画线条，笔画逐渐画出。
- **镜头**：聊天窗口里多是平滑推近到话题和输入框；状态卡片和按钮单独放大。
- **节奏**：10 个剪辑点，中间有三个 0.4–0.6 秒的快切，约 93 BPM。

## 换成 MosMos

在聊天里叫助手 → 在话题回复框里按 Fn 用 MosMos 说话；状态卡片 → MosMos 会议记录的进度（转写、区分说话人、整理待办、润色）；会话页 → MosMos 会议记录窗口的步骤；代码块 → 逐字稿片段；结果说明 → 会议纪要；绿色按钮 → 「已发送」。聊天窗口是通用样式，没有用参考片里那款软件的配色和图标。

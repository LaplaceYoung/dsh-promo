# 参考片拆解：Anysphere (Cursor) · Introducing Cursor 2.0 and Composer

- 出处：Anysphere (Cursor) 官方 YouTube，2025，<https://www.youtube.com/watch?v=An8IM-kPyms>
- 规格：原片 1080p，60 fps，64.48 秒，整体响度 −29.3 LUFS，约 113 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部安静的软件发布片。浅灰底上一个立方体标志和版本号，接着无光标的打字字卡逐句介绍新模型和新界面；中间夹一张横向柱状图对比；然后很长的产品演示都放在一张风景壁纸上的应用窗口里，镜头在侧栏、输入框、多栏结果、代码对比和内置浏览器之间推拉，换场多数是叠化；最后黑底标志和字标。

## 视觉规则

- **配色**：浅灰 #F2F2F0 左右的底，黑字；产品界面白色；风景壁纸只在窗口镜头里出现。
- **字体**：无衬线中等字重，居中，逐字打出，不显示光标。
- **镜头**：窗口镜头几乎都是缓慢的推近或平移，推到局部（侧栏、输入框、某一栏），再拉回。
- **节奏**：只有 8 个硬切；字卡和界面之间大多是 0.3–0.4 秒的叠化，配乐很轻。

## 换成 MosMos

立方体标志 → MosMos 像素标志；模型对比柱状图 → 两组示意柱状图（标注「示意，非实测」）；多模型并行 → 同一句话三档润色并排写出；代码审阅 → 原话与润色结果的删改对比；内置浏览器 → 会议记录窗口（摄像头小窗用 Pexels 公开授权视频）。

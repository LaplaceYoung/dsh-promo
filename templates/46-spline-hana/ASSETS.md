# 素材来源

| 文件 | 用在哪里 | 标题 | 作者 | 来源 | 许可 |
|---|---|---|---|---|---|
| 系统字体（不进仓库，`templates/_engine/scripts/fetch-fonts.sh` 下载） | 标题和正文 | Noto Sans SC / Noto Serif SC 可变字重 | Google Fonts / Adobe | <https://github.com/google/fonts/tree/main/ofl/notosanssc> | [SIL OFL 1.1](https://openfontlicense.org) |
| 系统字体（不进仓库，`templates/_engine/scripts/fetch-fonts.sh` 下载） | 像素字标、像素菜单、卡片和片尾文字 | Fusion Pixel Font 12px Proportional zh_hans（2026.10.25 版） | TakWolf | <https://github.com/TakWolf/fusion-pixel-font> | [SIL OFL 1.1](https://openfontlicense.org) |

像素字体不进仓库，由 `fetch-fonts.sh` 从作者的 GitHub Release 下载。画板上的缩略图是本片前面镜头的画面。其余画面（图标、按键、菜单、卡片、几何和渐变）是代码画的，配乐和音效用 numpy 合成。

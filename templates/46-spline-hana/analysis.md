# 参考片拆解：Spline · Introducing Hana - A new canvas for interactivity

- 出处：Spline 官方 YouTube，2025，<https://www.youtube.com/watch?v=ZsYijIY7qBA>
- 规格：原片 30 fps，26.73 秒，整体响度 −17.5 LUFS，约 129 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部 27 秒的快切预告。黑底像素字标，霓虹线框图标，线条动画，科幻 HUD，浅紫底按键，组件拼贴，等距线框，像素菜单，扇形卡片，彩色几何，像素字回声，深色画板上的推拉，最后像素字标故障和渐变球。

## 视觉规则

- **配色**：黑底和浅灰底交替，霓虹紫、品红、青做强调，片尾是粉蓝黄渐变。
- **字体**：像素字体做标题和菜单，界面小字无衬线。
- **镜头**：大多硬切，画板上推拉，两次一帧闪白。
- **节奏**：23 个剪辑点，约 129 BPM。

## 换成 MosMos

交互设计工具 → MosMos；交互状态和事件 → 快捷键（Fn、Fn + Shift、Right Alt、Alt + M）、润色三档；组件库 → 场景、热词、会议记录、待办；画板 → MosMos 设置和本片镜头的缩略图；3D 渐变球 → 渐变圆和像素标志。不用参考片的标志和界面。

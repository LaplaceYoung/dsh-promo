# 参考片拆解：Introducing Linear Releases

- 出处：Linear 官方 YouTube，2026-04-30，<https://www.youtube.com/watch?v=6dIwFoQ0eVg>
- 规格：1920×960（2:1），60 fps，30.07 秒，整体响度 −24.7 LUFS（很安静）
- 方法同模板 03：原生帧逐帧差分找剪辑点和打字时间，4 fps 抽帧通读，关键帧抄字、取色，onset 自相关 + 网格拟合求速度。参考片素材只留在本地。

## 一句话

纯黑背景上，无数条细白线从左边散开、向右汇成一点，像一棵横着长的树；每条线起点挂着一个工单编号。镜头在倾斜的 3D 面板上慢慢移动，景深很浅。中间一张等宽字卡，最后用一个方块光标打出 RELEASES、整词删掉、再打出 AVAILABLE NOW，切 logo。

## 视觉规则

- **配色**：几乎全黑（#000000 / #080808 占 85% 以上），线条和文字是 #E8E8EC 一类的冷白，面板底色 #101010–#181818。唯一的彩色是面板标题旁的一个小绿点。
- **字体**：全部等宽字，大写，字距放宽；logo 是 Linear 自己的无衬线字标。
- **线条**：0.8–2.4 px 的贝塞尔曲线，从左侧大范围散开，在右侧约 80% 宽度处汇聚；有亮点沿线流动。
- **3D**：面板沿 X 轴倾斜 30–50°、略带 Z 轴旋转；景深只有中间一条带是清晰的，前后都虚。
- **节奏**：只有 4 刀可见硬切，其余靠淡入淡出和面板滑入。

## 节拍

- librosa、自相关、网格拟合三种方法都指向 **110 BPM**（自相关峰 0.267 / 0.824 / 1.091 / 2.183 s，网格起点偏移约 0.136 s）。
- 音乐是很轻的合成器铺底，响度只有 −24.7 LUFS。22–26 秒最强的一串 onset 其实是打字声，和画面上的字母逐个对应。
- 剪辑点不严格卡拍。26.5 logo 出现后能量迅速掉到接近静音。

## 动效词汇

线条描边生长；亮点沿路径流动；景深带移动；面板 3D 滑入；字卡硬进软出；方块光标打字、整词删除。

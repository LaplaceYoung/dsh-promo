## 一句话

一部暗色、克制的代码审阅功能片，和同一家公司的 Linear Agent 片是同一套语言：界面躺在倾斜的平面上，浅景深的清晰带跟着内容走。先是侧栏微距和一列待审阅的条目，然后是红绿逐行对比、标签微距、左右分栏的说明和对比、一颗紫色的提交按钮、行内评论，最后黑底一句话和标志。

## 视觉规则

- **配色**：近黑界面，红色删除行、绿色新增行，紫色只用在主按钮上；外圈暗角。
- **镜头**：每个镜头都在倾斜平面上慢慢平移或推近，没有快速运动；微距镜头（标签、按钮）景深更浅。
- **字体**：等宽字体的行号和代码，界面字是小号无衬线；结尾一行白字。
- **节奏**：7 个硬切，平均 6–7 秒一个，配乐慢（检测在 87 和 117 BPM 之间）。

## 换成 MosMos

代码对比 → MosMos 的原话与润色对比（红色是口头禅、重复和写错的人名，绿色是润色后的句子）；条目 → 待确认的润色；Diff 标签 → 原话 / 润色 / 对比；提交审阅 → 确认润色；行内评论 → 对某一行说一句话修改；结尾字 → 「看清每一处改动」。

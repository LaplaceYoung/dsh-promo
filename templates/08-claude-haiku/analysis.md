# 参考片拆解：Introducing Claude Haiku 4.5

- 出处：Anthropic 官方 YouTube，2025-10，<https://www.youtube.com/watch?v=ccQSHQ3VGIc>
- 规格：1920×1080，60 fps，40.08 秒，整体响度 −9.1 LUFS
- 方法同模板 03：原生帧逐帧差分找剪辑点，4 fps 抽帧通读，关键帧抄字、取色，onset 自相关 + tempogram 求速度。参考片素材只留在本地。

## 一句话

橙色底上一幅黑色线描侧脸，白色节点一颗颗连成星座，收成一个点；点长成圆角方块，再长成对话窗口。提示词打进去，一个计时徽标跟着跑；镜头在对话、代码 diff 和做出来的网页之间来回推。最后一堆窗口缩回一个点，衬线字三行配一道绕字的白色笔触，型号名，火花，Claude 字标。

## 视觉规则

- **配色**：整片只有一种底色（Claude 橙），界面是白卡片，字是深灰。强调只有白色笔触。
- **形状语言**：一切从一个点出发、回到一个点。窗口不是切进来的，是从点长出来的。
- **字体**：界面里是无衬线；结尾三行和型号名用衬线，字号不大，居中。
- **计时徽标**：黑色圆角小方块，白字秒数，一直钉在窗口角上，中段放大到画面中央一次。
- **镜头**：在同一张大画布上推拉摇移，靠运动带出「切」，真正的硬切只有 7 个。
- **节奏**：前 4 秒很慢；中段快，代码和网页交替；结尾又慢下来。

## 节拍

- librosa 和网格拟合都给出 **97–98 BPM**（一拍约 0.615 秒），按 97 处理，首拍约 0.32 秒。
- 音乐是钢琴和弦加轻打击，前 9 秒几乎只有和弦，徽标出现后鼓进来，37 秒后收成一个延音。
- 节点亮起和「火花」都卡在拍上。

## 动效词汇

点长成窗口；窗口收回成点；节点连线；计时徽标钉在角上；镜头在大画布上推拉；diff 红绿行；马赛克缩小；绕字笔触；火花。

## 换成 MosMos 的对应

| 参考 | MosMos 版 |
|---|---|
| Claude 橙底 | MosMos 品牌蓝底，线描换成白色 |
| 侧脸 + 节点星座 | 同样的说话侧脸，节点是从嘴边发出的声音 |
| 提示词逐字打入 | 一段口语原话（官网 `COPY.raw`）逐字流入窗口 |
| 秒数计时徽标 | 字数徽标「NN 字」，一路数到 128 |
| 代码 diff 红绿行 | 润色 diff：删掉的口头语标红，整理后的句子标绿 |
| 生成出来的网页 | 写进飞书的那条消息（自绘界面） |
| 窗口马赛克 | 15 个场景窗口（聊天、邮件、文档、提示词、终端）拼成马赛克 |
| Lean model, rich mind… | 说得随意，/ 写得体面，/ 在每个应用里。（白色衬线字，黄色 #f2b134 笔触，蓝底上深色字不清楚，所以换成白字） |
| Haiku 4.5 → Claude | MosMos（衬线）→ 火花 → logo + 字标 |

帧率保持 60 fps，剪辑点时间按帧对齐。

# 参考片拆解：Anthropic · An experimental new way to design software

- 出处：Anthropic 官方 YouTube，2025，<https://www.youtube.com/watch?v=dGiqrsv530Y>
- 规格：原片 1080p，59.94 fps，102.01 秒，整体响度 −18.6 LUFS，约 85 BPM
- 方法同模板 03：本地下载到仓库外，用逐帧差分和 ffmpeg scdet 找剪辑点，用节拍检测量速度，按剪辑点抽关键帧看构图和运动。

## 一句话

一部 102 秒的演示片，节奏很慢。淡紫底上飘着白线，底部是输入条和几个建议；用户说一句话，桌面窗口就打开，里面是文件夹、文档、表单和游戏；右边一直有一个小面板记录输入；最后米白底标志。

## 视觉规则

- **配色**：淡紫底，白线，米白窗口，橙色只用在发送按钮上。
- **镜头**：大多不动，输入时推近底部输入条约 1.9 倍。
- **节奏**：6 个剪辑点，约 85 BPM，最后约 7 秒是标志。

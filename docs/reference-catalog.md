# 参考片目录

这份目录收集了做 MosMos 模板时用来研究的产品宣传片、功能演示片和制作片。每条都是官方 YouTube 频道上的公开视频，链接都用 yt-dlp 实际下载验证过（2026 年 11 月）。

仓库里不存放任何参考片的画面、音频或视频。复刻时只记录镜头时间、节奏和运动方式，再用 MosMos 自己的界面、文案和合成音乐重新制作。
